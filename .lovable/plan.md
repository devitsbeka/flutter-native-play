
# გეგმა: ჭკვიანი ძიების გაუმჯობესება აიკონების არჩევაში

## პრობლემა
როცა მომხმარებელი წერს "kata" (კატა ლათინურად), სისტემა ვერ პოულობს კატასთან დაკავშირებულ აიკონებს. ეს იმიტომ ხდება, რომ ლათინური ასოების ქართულად გადაყვანა არაზუსტია (თ და ტ ორივე შეიძლება იყოს "t").

---

## რას გავაკეთებ

### 1. ფონეტიკური ვარიანტების დამატება
`smart-icon-search` Edge Function-ში დავამატებ ლოგიკას რომელიც:
- ლათინური "t"-ს გარდაქმნის როგორც "თ"-ზე, ასევე "ტ"-ზე
- ლათინური "k"-ს გარდაქმნის როგორც "კ"-ზე, ასევე "ქ"-ზე
- შექმნის ყველა შესაძლებელ კომბინაციას

მაგალითი: "kata" → ["კათა", "კატა", "ქათა", "ქატა"]

### 2. პირდაპირი ლათინურ-ქართული ლექსიკონი
დავამატებ ხშირად გამოყენებული ლათინური ტრანსლიტერაციების პირდაპირ რუკას:

```text
kata     → cat, kitten, pet
dzaghli  → dog, puppy, pet  
veshapi  → whale, ocean
lomi     → lion, cat, wild
cxeni    → horse, equine
...
```

### 3. Fuzzy Matching გაუმჯობესება
- გავაძლიერებ Levenshtein distance შემოწმებას მოკლე სიტყვებისთვის
- დავამატებ phonetic similarity შემოწმებას

---

## ტექნიკური დეტალები

### Edge Function ცვლილებები (`smart-icon-search/index.ts`)

**ახალი ფონეტიკური ვარიანტების ფუნქცია:**
```text
// ფონეტიკურად მსგავსი ქართული ასოები
const PHONETIC_VARIANTS = {
  'თ': ['თ', 'ტ'],  // t sounds
  'ტ': ['თ', 'ტ'],
  'კ': ['კ', 'ქ'],  // k sounds  
  'ქ': ['კ', 'ქ'],
  'პ': ['პ', 'ფ'],  // p sounds
  'ფ': ['პ', 'ფ'],
};
```

**ახალი პირდაპირი transliteration რუკა:**
```text
const LATIN_TRANSLITERATIONS = {
  'kata': ['cat', 'kitten', 'pet', 'feline'],
  'dzaghli': ['dog', 'puppy', 'pet', 'canine'],
  'veshapi': ['whale', 'ocean', 'mammal'],
  'lomi': ['lion', 'cat', 'wild', 'king'],
  'datvi': ['bear', 'wild', 'forest'],
  'zvigeni': ['shark', 'fish', 'ocean'],
  'cxeni': ['horse', 'equine', 'riding'],
  'spilo': ['elephant', 'animal', 'trunk'],
  ...
};
```

**გაუმჯობესებული ტრანსლიტერაციის ლოგიკა:**
1. თუ მომხმარებელი შეიყვანს ლათინურ ტექსტს (მაგ. "kata")
2. ჯერ ვამოწმებთ `LATIN_TRANSLITERATIONS` რუკაში პირდაპირ
3. თუ არ მოიძებნა - ვაგენერირებთ ფონეტიკურ ვარიანტებს
4. ყველა ვარიანტს ვამოწმებთ `GEORGIAN_TO_ENGLISH` რუკაში

## შედეგი

ძიების მაგალითები გაუმჯობესების შემდეგ:
- "kata" → კატები, კნუტები, შინაური ცხოველები
- "dzaghli" → ძაღლები, ლეკვები  
- "lomi" → ლომები, დიდი კატები
- "cxen" → ცხენები
- "veshap" → ვეშაპები
